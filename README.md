# Gestão de Chamados de TI

Projeto de implantação de um sistema de gestão de chamados de TI, utilizando práticas de gerenciamento de projetos e metodologias ágeis.

## 🎯 Objetivo

Implantar um sistema para centralizar, organizar e acompanhar os chamados de TI, melhorando o controle das solicitações e o acompanhamento das demandas.

## 📋 Projeto

O projeto contempla o planejamento da implantação, levantamento de requisitos, organização do backlog, definição das etapas e acompanhamento das entregas.

## 🛠️ Metodologia

- Gerenciamento de Projetos
- Scrum
- Backlog
- Priorização de demandas
- Acompanhamento de entregas

## 📌 Principais entregas

- Levantamento de requisitos
- Criação e priorização do backlog
- Planejamento da implantação
- Definição das atividades
- Acompanhamento das entregas
- Registro das lições aprendidas
