# Checklist de Implantação — Gestão de Chamados de TI

Checklist operacional utilizado para conduzir e validar cada etapa da implantação do sistema e do fluxo de atendimento.

---

## Fase 1 — Levantamento e Diagnóstico
- [x] Mapear canais atuais por onde chegam as solicitações de TI
- [x] Identificar os tipos de chamados mais recorrentes
- [x] Levantar principais gargalos de triagem, comunicação e prazo
- [x] Definir requisitos mínimos para o novo processo

## Fase 2 — Desenho do Processo e Regras
- [x] Definir categorias e subcategorias de atendimento
- [x] Estruturar ciclo de vida e status do chamado
- [x] Definir campos obrigatórios do formulário de abertura
- [x] Estabelecer matriz de prioridade (Impacto x Urgência) e SLAs
- [x] Definir regras de pendência (`Aguardando Solicitante` / `Aguardando Terceiros`)

## Fase 3 — Configuração e Testes
- [x] Configurar categorias, status e filas no sistema
- [x] Configurar perfis de acesso (solicitante, analista, administrador)
- [x] Validar notificações de atualização e encerramento
- [x] Realizar testes ponta a ponta de abertura, triagem, atendimento e fechamento
- [x] Corrigir ajustes identificados nos testes

## Fase 4 — Piloto e Alinhamento
- [x] Elaborar guia rápido de abertura de chamados para usuários
- [x] Alinhar fluxo de triagem e critérios de priorização com a equipe técnica
- [x] Validar o fluxo em cenário piloto e coletar feedback inicial

## Fase 5 — Virada (Go-Live) e Acompanhamento
- [x] Oficializar o canal único de abertura de chamados
- [x] Monitorar volume diário, cumprimento de SLA e taxa de reabertura
- [x] Realizar ajustes finos nas categorias e regras após as primeiras semanas
- [x] Registrar lições aprendidas do projeto
