# Plano de Implantação — Gestão de Chamados de TI

## Objetivo

Organizar as etapas necessárias para implantação do sistema de gestão de chamados de TI.

## Etapas

| Etapa | Atividade | Responsável | Status |
|---|---|---|---|
| 1 | Levantamento de requisitos | Equipe do projeto | Concluído |
| 2 | Definição das categorias de chamados | Equipe do projeto | Concluído |
| 3 | Definição do fluxo de atendimento | Equipe do projeto | Concluído |
| 4 | Configuração do sistema | Equipe de TI | Em andamento |
| 5 | Testes e validação | Equipe de TI e usuários | Pendente |
| 6 | Treinamento dos usuários | Equipe do projeto | Pendente |
| 7 | Implantação | Equipe de TI | Pendente |
| 8 | Acompanhamento pós-implantação | Equipe de TI | Pendente |

## Critérios para conclusão

A implantação será considerada concluída quando:

- O sistema estiver configurado;
- Os fluxos de atendimento estiverem validados;
- Os testes forem concluídos;
- Os usuários forem orientados;
- O sistema estiver disponível para utilização.
