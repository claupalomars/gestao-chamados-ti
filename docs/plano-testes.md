# Plano de Testes e Validação — Gestão de Chamados de TI

## Objetivo

Validar o funcionamento do sistema de gestão de chamados antes da implantação definitiva.

## Cenários de Teste

| ID | Cenário | Resultado Esperado | Status |
|---|---|---|---|
| T01 | Abrir novo chamado | Chamado registrado com sucesso | Pendente |
| T02 | Classificar chamado | Categoria identificada corretamente | Pendente |
| T03 | Definir prioridade | Prioridade atribuída conforme critérios | Pendente |
| T04 | Alterar status | Status atualizado corretamente | Pendente |
| T05 | Encerrar chamado | Chamado finalizado e registrado | Pendente |
| T06 | Consultar histórico | Histórico disponível para consulta | Pendente |

## Critérios de Validação

- Todos os campos obrigatórios devem funcionar.
- As categorias devem estar configuradas.
- As prioridades devem seguir as regras definidas.
- O fluxo de atendimento deve funcionar corretamente.
- O histórico dos chamados deve estar disponível.

## Resultado Esperado

Garantir que o sistema esteja preparado para utilização, atendendo aos requisitos definidos no projeto.
