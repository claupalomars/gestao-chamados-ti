# Lições Aprendidas — Gestão de Chamados de TI

## Pontos positivos

- Organização das demandas por meio do backlog.
- Definição clara das prioridades.
- Documentação das etapas de implantação.
- Identificação antecipada dos principais riscos.
- Acompanhamento das atividades por status.

## Pontos de atenção

- Garantir que todos os requisitos sejam validados antes da configuração.
- Manter os usuários envolvidos durante os testes.
- Comunicar alterações no fluxo de atendimento.
- Acompanhar os chamados após a implantação.

## Melhorias para projetos futuros

- Realizar reuniões de alinhamento com maior frequência.
- Registrar decisões importantes durante o projeto.
- Antecipar possíveis impactos das mudanças.
- Utilizar os aprendizados deste projeto como referência para novas implantações.

## Conclusão

As lições aprendidas serão utilizadas para melhorar o planejamento, a comunicação e o acompanhamento de futuros projetos de implantação de sistemas de TI.
